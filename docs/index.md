# TOWER documentation

TOWER evaluates long-horizon tower manipulation policies across twelve task
variants. Public benchmark revision **2026.11.1** uses `tower-scene-v2`: a redacted
scene representation with unchanged physical scenes and an old-to-new scene map.
Package versions, benchmark revisions and wire schemas have separate identities;
see [versioning](reference/versioning.md) and the [public benchmark](reference/bench-public.md).

Choose a starting point:

- [Benchmark user](getting-started/quickstart-benchmark-user.md): install and evaluate.
- [Policy author](getting-started/quickstart-policy-author.md): connect a model.
- [Contributor](getting-started/quickstart-contributor.md): develop and validate changes.

Weights are not bundled. Model cards will be published with the checkpoints.
CPU smoke checks validate integration, not physics.
