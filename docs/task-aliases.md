# Task aliases

See the [task registry](concepts/tasks.md). Canonical task names, paper letters
and legacy numeric ids resolve to the same task identity. Use canonical names
in new reports. Aliases do not change geometry, timing or scoring.

Accepted forms include canonical ids (`two-block-transfer-3`), paper ids (`B3`,
`B-3`), numeric aliases (`task13`, `Task1-3`) and retained layout ids
(`tower_transfer_3`). Resolution is case-insensitive. Bare family names require
a layer count; unknown names fail with suggested matches.
