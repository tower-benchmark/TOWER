# Reproducing benchmark results

The paper's evaluation harness is not part of this distribution.

Use public benchmark revision 2026.11.1 (`tower-scene-v2`) with its matching
runtime and verified assets. Record
package versions, resolved configuration, scene identity, policy checkpoint
digest, runtime settings and scoring ruleset. Verify input hashes before running.
Follow the [benchmark guide](../reference/bench-public.md).

Paper results and new public
benchmark measurements must be labelled separately; physical scene equivalence
alone does not establish equivalence of policies or evaluation protocols.
