# Versions and protocols

Packages use semantic versions; benchmark data uses calendar revisions; wire
schemas have independent numbered identities. Public revision 2026.11.1 uses
`tower-scene-v2`, preserving physical scenes while removing private provenance.
An old-to-new scene map establishes identity across representations.
See [versioning](../reference/versioning.md) and [benchmark data](../reference/bench-public.md).
