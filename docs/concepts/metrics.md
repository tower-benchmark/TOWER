# Metrics

Task success measures completion under the released task-specific rule.
Grasp/place rates measure operation completion; long-horizon progress and
operation disturbance are separate measures. Never replace missing physical
evidence with CPU smoke results. See the [scoring reference](../reference/scoring.md).

The [scoring specification](../reference/scoring.md#scoring) defines successful
G/P operations, C = G + P, E = C + 1 − s, and the >10 mm disturbance threshold.
Task-specific overrides are listed in its ruleset table.
