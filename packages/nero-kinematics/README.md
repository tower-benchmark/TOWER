# Nero kinematics

Convert absolute TCP poses and measured joints into joint targets using
Pinocchio, CasADi and IPOPT. Simulation reference models are included;
hardware calibration and testing remain deployment responsibilities.

See the [install, API, JSONL CLI and acceptance reference](https://docs.tower-benchmark.com/reference/kinematics/)
and [control safety contract](https://docs.tower-benchmark.com/guides/eef-control/#control-safety-contract).
