# Nero kinematics

Convert absolute TCP poses and measured joints into joint targets using
Pinocchio, CasADi and IPOPT. Simulation reference models are included;
hardware calibration and testing remain deployment responsibilities.

See the [install, API, JSONL CLI and acceptance reference](https://tower-benchmark.github.io/TOWER/reference/kinematics/)
and [control safety contract](https://tower-benchmark.github.io/TOWER/guides/eef-control/#control-safety-contract).
