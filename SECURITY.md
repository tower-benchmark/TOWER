# Security policy

Report vulnerabilities privately through the repository's Security tab using
GitHub private vulnerability reporting, when enabled. See
[GitHub's reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).
Do not include vulnerability details in a public issue.

Security email: admin@tower-benchmark.com.

The integration branch is under active development. Reports should include the
commit or release, affected component, reproduction steps and potential impact.
